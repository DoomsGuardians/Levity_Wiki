# 配给网

**配给网**是[[Aeros]]将[[生产海]]产出输送到人口、并将废物回流到回收段的物质循环系统。如果说[[神机网络]]是Aeros的神经系统，配给网就是它的**循环系统**——血管、肠道与排泄道合一。它是一套物质封闭系统中维持上千万人的物流骨架，也是[[戒子系统|戒子]]失声后最先碎裂的东西。

---

## 双向物流

配给网由两条方向相反的流构成，对应[[生产海]]作为闭合生态系统的物质守恒账本。

### 正向：产出配给

```
生产海（初级生产、加工） → 轨道干道（跨区运输） → 节点城（区域集散） → 人口（消费）
```

固定设施接在[[中间层]]超导电网上，自动化货运轨道列车在生产海底层和干道走廊中昼夜运行。普通人一生接触配给网的方式，就是从节点城的分发点领取自己那一份——他们是这条链末端的**消费者，不是生产者**。

### 逆向：废物回流

```
人口（代谢废物、不可食生物量、尸体） → 回流支线 → 生产海（分解矿化段） → 营养池
```

在物质封闭的系统里，逆向物流不是可选项而是**铁律**——碳、氮、磷、水的总量固定，消费掉的必须回流，否则系统会因营养枯竭而停摆。这意味着一个冷酷的事实：**人（包括死者）本身就是配给网的物质节点**。治理良好的地区把死者有序回收进营养池；秩序崩坏的地区则把尸体直接倾倒进[[大空洞]]——那部分物质就**永久漏出了闭环**，再也回不来。

---

## 戒子时代的全局调度

[[戒子系统|戒子]]完整运行时，配给网由[[存基]]（读取全局感知）、[[忆室]]（调用档案）、[[策网]]（向[[神机网络|神机]]原始层下达指令）协同，做**全局最优调度**：哪个区域产出过剩、哪个区域短缺，物资在整张网上动态平衡。从系统视角，整个中间层是一个被统一记账、统一调配的单一器官。

---

## 失声后的碎裂

[[密钥]]夺取后[[戒子系统|戒子]]失声，[[元枢]]又在[[崩落战役]]中被毁——配给网失去了它的全局协调层，且**永久无法恢复**。

每个[[神机网络|神机]]节点退回本地自主运行，只能按最后预设参数维持本辖区。后果是：

- **局部失衡常态化**：A州的仓库里粮食烂掉，B州却在饥荒——因为没有任何一层还能看到全局、做跨区调度。丰与歉不再被熨平。
- **干道枢纽 = 权力**：谁控制轨道枢纽和干道走廊，谁就掐住了配给的咽喉。这是[[战争游戏]]反复争夺干道节点的物质根基，也是诸侯权力的实体来源。
- **净明教的威慑落到实处**：[[净明教]]用[[策网]]能向原始层下"配给给谁"的指令，"违规者切断生产海供应"不是空话，而是直接操作这张网的能力。

---

## 文明的失败模式：物质预算泄漏

配给网揭示了[[生产海]]衰退**不可逆**的真正物理原因——不是设备老化，而是**物质账本的持续亏损**。

闭环没有100%效率，每一次循环都有微量物质锁进不可回收的形态。但真正致命的是**人为的泄漏**：

| 泄漏方式 | 永久损失的物质 |
|----------|----------------|
| 尸体倾倒进[[大空洞]]而非回流 | 锁在人体里的碳氮磷 |
| 区域分区被泄入大空洞或失控区 | 整片营养与设备 |
| 战争摧毁生产海设施 | 设施物质 + 其承载的产能 |
| [[回收经济|原质]]材料被熔铸成死质 | 不可逆的性能与结构 |

在一个造不出新物质的封闭系统里（这与[[回收经济]]"只能回收、不能制造"是**同一条物理定律**），每一克漏出的物质都是从文明的总账里**永久扣除**。于是浮现出整个世界最冷的图景之一：**人类在自相残杀中，正加速消耗自己赖以存活的物质总量。** 系统不会轰然崩塌，它会在灯火通明中被一点点抽干——核心层的聚变"太阳"还能烧几千年，天还亮着，但账本在一克一克地见底。

> [!question] 存疑
> 配给网失声后究竟漏损了多少物质总量？是否存在某些地区仍在勉强维持完整的回流闭环（如[[净明教]]直辖区或[[练氏]][[天机]]）？这关系到"倒计时"还剩多久，目前未定量。
