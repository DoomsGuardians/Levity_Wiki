# 楷国疆域

本词条是[[晓朝舆图]]在[[楷国]]一国的放大，把[[舆图基质]]给出的三把尺子——**财富哪来 / 靠什么关守 / 哪场战争冻结**——真正落到十三州的具体疆界上。它回答一个长期被搁置的问题：楷国的十三州分布在哪、谁守海谁守关，以及为什么六卿"领地犬牙交错、谁也无法自立"不是一句空话，而是被脚下地形几何逼出来的必然。

> [!info] 三层文档
> [[晓朝舆图]]给整个晓朝的版图，[[舆图基质]]给版图底下的成因，本词条给楷国这一国的实图。**线画在哪、为什么画在那，在这里第一次对上号。**

---

## 一句话图景

楷国是一块**护在中央的肥海，被一圈饥饿的关隘锁在里面**。

最肥的生产海带缩在国土中央（楷君与颜、榛二卿坐拥），四面被[[叶氏]]的关隘要塞环抱；唯一的东缘咽喉，是握着两枚[[密钥]]的囚徒——[[天机]]·[[练氏]]；唯一的西北缺口，顶着无人机的衰退锋。守海的喂不饱军队，守关的种不出粮食，扼管路的谁也得罪不起。十三州谁也离不开谁——这正是楷国四百年裂而不分的地理底座。

---

## 拓扑：一盆肥海，一圈饿关

楷国的实际地形不是平面色块，而是**一个中央生产海盆地，外面套一圈结构关隘环**。两套几何（肥的海 / 险的关）在这里被[[舆图基质|基质]]的铁律拆开——它们互不对齐，于是谁也无法独活。

```
            西北：燧国 · 失控区
              ↓ 正在内缩的衰退锋
   ┌────────────────────────────────────┐
   │   ▒▒ 叶氏关隘环（北脊·承力巨梁）▒▒    │
   │  ┌──────────────────────────┐ ╲    │
   │ ▒│   ◎ 中 央 生 产 海 盆 地   │  ◇天机│ → 隶国
   │ 叶│  楷都·颜氏腹地·榛氏二州     │ （练氏）│
   │ 氏│  （最肥 · 几乎无险可守）    │ 东咽喉 │
   │ 环│                          │ ╱      │
   │  └──────────────────────────┘        │
   │   ▒▒ 叶氏关隘环（南脊·管沟）▒▒  ◣根氏  │
   └────────────────────────────────────┘
            东南：大空洞 · 原质矿脉 · 腐烂源

   ◎ 盆地 = 财富，无险      ▒ 叶环 = 险，无粮
   ◇ 天机 = 东咽喉，海毁    ◣ 根氏 = 坟唇边缘州
```

**读法**：盆地（颜、榛、楷君）有粮无险；叶氏的关隘环有险无粮；东咽喉（练氏）有路无粮；西北缺口顶着无人机；东南坟唇（根氏）穷而近矿。十三州沿这五个区位排开，每一块的命运都由"它分到的是海还是关"决定。

---

## 五个区位：把基质的尺子量到每一块地上

### ① 中央生产海盆地——财富，但无险可守

楷国保住了晓朝**西部最大的一片连续生产海带**（见[[舆图基质]]"近而不在伤口上"），这片海缩在国土中央，是整个楷国的肺。它供养着四五百万人口，是楷国稳坐十三州最强的物质底座。

但按基质铁律，**大片连续的海几乎必然无险可守**——它太大，没有任何单一关隘罩得住，地势在结构上是开阔的承力平台面。这正是[[央泽]]"海太大无颈可守"的同一几何，只是楷国的盆地被一圈关隘环**从外面**勉强兜住，才没沦为央泽那样的共管区。

坐拥盆地的是楷君（[[楷都]]直辖州）、颜氏腹地、与榛氏二州——**他们是楷国的粮仓，却也是最暴露的软腹**。

> 颜氏的腹地正在这片盆地里。这解释了为什么颜氏的崛起走的是**贸易而非武力**：守着最肥的海、却背靠最不可守的地形，硬拼军事是死路，唯有把生产海配额换成[[蓄器]]与人情债、用关系网替代关隘，才是这块地形上唯一的活法（见[[颜氏]]）。地理选择了颜氏的战略，不是反过来。

### ② 叶氏关隘环——可守性，但喂不饱

楷国中央盆地的北脊与南脊，是壳体的**承力巨梁与管沟骨架**所在——结构上的天险（同[[断梁关]]之"梁"、[[梁津]]之走廊原理）。控制这一圈关隘，就控制了进出盆地的所有结构走廊。

[[叶氏]]的三州正压在这条关隘环上。这是叶氏军事霸权的**地理根**，此前只被解释为"净明教技术输血"，现在补上了它的另一半：**叶氏的地盘本就是楷国的天险所在，机械化军队加天险，才锁死了军事第一的位置**。但关隘环的代价同样由基质写定——**险地无肥海**。叶氏辖区的生产海远不及中央盆地，养不起它那支吞蓄器的机械化大军，于是叶氏被迫向坐拥肥海的颜氏买蓄器、买配额。

**叶颜双峰的死结，根上是一道地理错位**：守关的（叶）养不活自己的军队，守海的（颜）守不住自己的粮仓。一个有刀没粮，一个有粮没刀。基质所谓"财富与可守性几乎从不重合"，在楷国内部被精确复刻成了叶、颜两家的相互掐喉。

### ③ 东咽喉·天机——有路无粮的囚徒

楷国的东缘，是[[天机]]·[[练氏]]一州。它扼守楷国通往[[隶国]]的**唯一结构走廊**——这是楷隶之争反复死磕天机的硬成因（见[[舆图基质]]）。

> [!warning] 已修正的方位
> [[天机]]旧词条称其在"楷国西侧边缘"，与[[晓朝舆图]]校准后的几何（自西向东＝楷国—天机—隶国）矛盾。天机应在**楷国东缘**、楷隶之界、[[大空洞]]北唇。本词条按新几何采"东咽喉"，天机词条已同步修正。

天机的命运是基质"纯关隘"格的教科书：**可守性极高（唯一通路上的关），财富几近为零（生产海在[[大空洞]]形成时尽毁）**。守得住却喂不饱，只能"以[[密钥]]换面包"。它被锁在楷国东缘绝非行政偶然——把握着两钥的囚徒钉在全国最关键也最贫瘠的咽喉上，由[[叶氏]]从西、隶国从东双重夹峙，是[[晓朝舆图]]"京畿与囚徒隔国相望"格局在楷国一侧的落点。

### ④ 西北缺口——与无人机对峙的衰退锋

楷国的西北角顶着[[燧国]]方向的失控区。这里没有邻国划的国界，只有[[舆图基质]]所说的**"正在内缩的结构衰败锋"**——电网在退潮，生产海在死，无人机在啃。

这一角的州是楷国最穷最悍的边州，承担着把失控区挡在盆地之外的盾牌职能，也吃边疆[[回收经济|拾荒]]红利。它是楷国"近而不在伤口上"的缓冲带：楷国靠这一圈边州替中央盆地挡刀，自己的肥海才得以安稳。

### ⑤ 东南坟唇——根氏的边缘州

楷国东南抵着[[大空洞]]北缘。[[根氏]]被贬后仅剩的一州，正落在这片靠近坟唇的边缘——离原质矿脉近、离中央盆地远、生产海平平。

这块地形把根氏的处境焊死了：**它既挨着全图最危险也最有价值的坐标（大空洞），又被隔在中央权力盆地之外**。根氏"暗中联络练氏"在地理上几乎是必然——两家都被甩在东缘的贫瘠带上，练氏在东咽喉、根氏在东南坟唇，是楷国地图上离权力中心最远、彼此却最近的两个弃子。

## 领地穿插：不是制度设计，是断电时碎出来的

[[楷国]]词条把"六卿领地犬牙交错、谁想独立都会发现地盘被切成碎片"解释为姬桦的**制度设计**。基质给出了它的更深一层成因——这种穿插**首先是地理的，制度只是把地理既成的碎裂固定下来**。

按[[舆图基质]]"第一阶"：Y0[[配给网]]失声时，[[中间层]]碎成无数**只能本地自维持的栅格**，每个[[神机网络|神机]]节点只管自己那一格的生产海。楷国这片土地在断电那一刻，就沿供电与物流的薄弱处天然裂成了一块块"一城＋一片海"的光岛——**它们从一开始就不是连续的版图，而是黑暗死结构里一座座互不相连的灯火孤岛**。

于是六卿"领地穿插"的真相是：

- 这些光岛**本就散布、互不接壤**，中间隔着断电的死结构走廊；
- 谁想把自己的几块岛连成一片自给的整体，都会发现**关键的连接走廊（巨梁、管沟）卡在别家或叶氏关隘环手里**；
- 姬桦做的不是"故意打散"，而是**承认并冻结**了配给网死亡时已经碎好的格局——他只是给天然的裂缝盖了行政图章。

**领地无法自成体系，根上不是君主的权术，是脚下这片地从断电那天起就没法连成一块。** 制度的制衡力，借的是地理的不可连续性。

## 边界从哪冻结：百家之乱在关隘上的落点

按[[舆图基质]]"第二阶"，楷国的外缘国界是[[百家之乱]]（Y15-Y110）的战争**沿结构走廊流动、在关隘处冻结**出来的：

| 边界段 | 卡在哪道结构颈上 | 冻结的战争 |
|--------|----------------|-----------|
| 楷·隶东界 | [[天机]]这道唯一走廊 | 楷隶反复争夺天机，谁也没能越过咽喉吞下对方核心，于是边界冻在练氏这道关上——练氏被夹成缓冲国般的存在 |
| 楷·燧西北界 | 通往失控区的衰退锋 | 不是与燧国打出来的，而是与失控区/无人机对峙、打到推不动了停下的内缩前沿 |
| 楷国东南界 | [[大空洞]]北唇 | 崩落带本身就是天堑，无需划线——没人会去争一片正在扩张的死海，边界自然抵着坟唇 |

楷国之所以是十三州中最大最强，正因为它在百家之乱里抢到了**那片中央肥海**，又用一圈关隘和边州把它兜住——既近大空洞吃得到拾荒与战略红利，又"不在伤口上"保住了核心生产海。这是[[舆图基质]]"近而不在伤口上，所以最强"那句话的完整展开。

## 这套地理反推出了什么

把三把尺子量完十三州，[[楷国]]词条里几条原本"靠人物性格"解释的政治主线，都浮出了硬地理成因：

- **叶颜为何必然双峰对峙**：守关的叶养不活军队、守海的颜守不住粮仓——一道地理错位，逼出两家相互掐喉的结构。
- **颜氏为何走贸易而非武力**：背靠最肥也最不可守的盆地，关系网是这块地形上唯一能替代关隘的防御。
- **练氏为何被锁在东咽喉**：全国唯一通路 × 生产海尽毁＝守得住却喂不饱，"以密钥换面包"是几何判决，不是惩罚。
- **根氏练氏为何天然结盟**：地图上离权力中心最远、彼此却最近的两个东缘弃子。
- **六卿为何谁也无法自立**：地盘从配给网断电那天起就是碎的，连不成片。

地理在前，性格在后。这正是当初建[[舆图基质]]要解决的"空中楼阁"问题——人物的算计，站在一片有重量的土地上。
