# Levity Wiki 词条格式标准

本文档定义知识库中各类词条的统一格式规范。

---

知识库按以下结构组织：

```
├── 核心概念/

├── 历史/

│   ├── 崩落战役/               # 崩落战役相关事件
```

## 一、通用规范

### 1. 基础结构
```markdown
# 词条名

**首段加粗定义**（包含时间、身份、核心信息，添加相关概念的[[内链]]）

---

## 主要内容章节

### 子章节

---

## 相关词条
- [[词条1]]
- [[词条2]]
```

### 2. 内链规范
- 首次提及关键概念时必须添加内链 `[[词条名]]`
- 可使用管道语法显示别名 `[[轻力场文明|LFC]]`
- 特定章节引用 `[[炼术#断域|断域]]`

### 3. 年份格式
- 统一使用 `Y` + 数字（如 Y110、Y-15）
- Y0 = 密钥夺取事件
- 负数表示密钥夺取前

## 二、人物词条格式

### 1. 重要人物（帝王、百炼核心成员、重要领袖）

```markdown
# 人物名

**人物全名/称号**（生卒年份），身份定义，核心成就，历史地位。

---

## 基本信息

| 项目 | 内容 |
|------|------|
| **代号/讳/姓名** | 具体内容 |
| **身份** | 主要身份描述 |
| **活跃时期/在位时期** | Y年份-Y年份 |
| **技术遗产/主要成就** | 核心成就 |
| **核心立场/观点** | 引语或概括 |
| **结局** | 去世方式或最终结局 |

---

## 生平

### 早年
### 某个重要时期
### 某个重大事件

---

## [可选专题章节]
- 技术遗产
- 核心观点
- 历史评价

---

## 相关词条
- [[相关词条列表]]
```

**示例**：晓烈帝、克鲁奇、塞里斯

### 2. 次要人物

```markdown
# 人物名

**人物名**（生卒年份），简明身份定义和核心事迹。
```

## 八、表格设计规范

### 1. 基本信息表
- 使用两列布局：`| 项目 | 内容 |`
- 项目名加粗：`| **项目** | 内容 |`
- 分隔线：`|------|------|`

### 2. 多列表格
- 清晰的列头：`| 列1 | 列2 | 列3 |`
- 适当的列宽平衡
- 必要时使用缩写

### 3. 表格位置
- 基本信息表：紧随首段分隔线后
- 专题表格：在相关章节内
- 对比表格：在对应分析文字前

## 九、格式检查清单

创建或修改词条时，检查以下要素：

- [ ] 首段加粗定义完整
- [ ] 必要的内链已添加
- [ ] 年份格式统一为Y格式
- [ ] 表格格式规范
- [ ] 章节结构清晰
- [ ] 相关词条章节完整
- [ ] 分隔线 `---` 正确使用
- [ ] 无错别字和标点错误
