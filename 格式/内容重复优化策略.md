# Levity Wiki 内容重复优化策略

本文档定义如何处理集合词条与专门词条之间的内容重复问题。

---

## 核心原则

### 单一信息源原则（Single Source of Truth）
- **专门词条**：包含完整、详细的信息（权威来源）
- **集合词条**：提供精炼摘要 + 链接到专门词条（导航功能）

### 信息分层原则
- **概览层**：集合词条提供宏观视角和脉络关系
- **详细层**：专门词条提供深度信息和细节
- **避免**：在两个层级重复叙述相同信息

### 链接优先原则
- 当需要引用其他词条的信息时，优先使用链接
- 集合词条中每个子主题应在50-200字内完成摘要
- 摘要结束时使用"详见[[专门词条]]"引导深度阅读

---

## 集合词条的标准格式

### 模板结构

```markdown
# 集合词条标题

**总述**：一段话说明本词条的覆盖范围和历史背景。

---

## [[子主题1]]

**简短定义**（时间范围），核心特征一句话概括。

**关键信息**：
- 要点1（10-15字）
- 要点2（10-15字）
- 要点3（10-15字）

**历史地位**：一句话总结其在整体中的位置。

**详见[[子主题1]]**

---

## [[子主题2]]

（同上）

---

## 相关词条
- [[相关词条1]]
- [[相关词条2]]
```

### 摘要编写规范

**摘要应包含（50-200字）**：
1. 定义性描述（是什么，时间范围）
2. 3-5个关键要点（列表形式）
3. 历史地位或结局（一句话）
4. 引导链接"详见[[XX]]"

**摘要不应包含**：
- 详细的事件经过
- 人物对话或引文
- 具体战役细节
- 复杂的因果分析

---

## 专门词条的标准格式

### 完整性要求

专门词条应包含：
- 完整的历史背景
- 详细的事件经过
- 深入的分析和评价
- 相关人物的具体言行
- 充足的内链

### 避免重复上层信息

专门词条中应避免：
- 重复宏观历史背景（如整个百家之乱的概述）
- 重复其他并列词条的信息
- 大段引用集合词条的内容

如需要背景信息，使用一句话+链接：
```markdown
在[[百家之乱]]的整合期，东庭成为最大的军阀联盟...
```

## 分类处理策略

### 第一类：势力集合词条（如"乱世势力"）

**优化前**：每个势力200-500字详细记述
**优化后**：每个势力50-100字摘要 + 链接

**示例对比**：

❌ **优化前**（详细记述）：
```markdown
## 东庭

东庭位于中间层顺流偏暗向区域（传统上称"东部"），是文况旧部经过数代反复兼并后形成的松散联盟。

### 形成
文况在Y26年被弑后，他的地盘分裂为四块。此后数十年，这些碎片以及周边中小军阀反复兼并、分裂、再兼并。到Y60年左右，一个名义上统一的联盟逐渐成型...

（还有200字）
```

✅ **优化后**（精炼摘要）：
```markdown
## [[东庭]]

**东庭**（Y60-Y110），百家之乱整合期最大的军阀联盟，由文况旧部经数代兼并演化而成。

**核心特征**：
- 体量最大但凝聚力最弱
- 名义盟主轮替，各军阀各怀鬼胎
- 隶氏为最强成员，后成为晓朝[[隶国]]

**覆灭**：Y102-Y110年，[[晓武帝]]以分化瓦解方式八年完成征服，东庭内部连锁投降。

**详见[[东庭]]**
```

---

### 第二类：人物集合词条（如"乱世群雄"）

**优化前**：每个人物100-300字详细传记
**优化后**：每个人物30-80字关键信息 + 链接

**示例对比**：

❌ **优化前**（详细传记）：
```markdown
### 文况

流放派联盟中最强大的军事将领。明渠事件的策划者，崩落战役中联军的实际军事指挥者。

文况是乱世中最纯粹的"武力信仰者"。他的名言——"刀剑不需要解释"——精确概括了他的全部政治哲学...

（还有150字）
```

✅ **优化后**（关键信息）：
```markdown
### [[文况]]

流放派最强军事将领，[[明渠事件]]策划者，Y26年被部下刺杀。"刀剑不需要解释"——纯粹的武力信仰者，能打天下不能治天下的典型。其旧部演化为[[东庭]]联盟。
```

---

### 第三类：时期总述词条（如"百家之乱"）

**优化前**：每个时期详细记述人物、事件、思想
**优化后**：保留时期划分和脉络，具体内容链接专项词条

**示例对比**：

❌ **优化前**（详细记述）：
```markdown
### 第二期：大分裂（Y15-Y35）

文况试图通过军事力量统一中间层，发动三次统一战争...
（详细描述三次战争、文况的治理政策、被刺杀经过等，共300字）
```

✅ **优化后**（脉络概述）：
```markdown
### 第二期：大分裂（Y15-Y35）

**核心特征**：流放派联盟解体，中间层陷入全面混战

**关键事件**：
- 孟遂去世（Y12）→ 联盟名义领袖消失
- [[文况]]三次统一战争失败（Y18-Y24）
- 文况被刺（Y26）→ 东部势力分裂为四块

**演化趋势**：从"统一尝试"到"区域割据"

**详见**：[[文况]]、[[东庭]]、[[乱世群雄]]
```

---

### 第四类：组织演化链（如"百炼→崩落派"）

**优化策略**：明确时间分界点，避免重复叙述

**分工方案**：
- **百炼词条**：Y-15到Y3，聚焦思想研究与三派分裂
- **崩落派词条**：Y3到Y5，聚焦激进化与军事行动
- **明渠事件词条**：Y3单一事件的详细记述
- **崩落战役词条**：Y5战役的详细记述

**衔接方式**：
```markdown
# 百炼（结尾）

...Y3年[[明渠事件]]后，激进派完全掌权，组织性质发生根本转变。
**此后历史详见[[崩落派]]**

---

# 崩落派（开头）

**崩落派**是[[百炼]]在Y3年[[明渠事件]]后激进化的产物...
（接续百炼的历史，但不重复明渠事件细节）
```

## 优化执行顺序

### 阶段1：高优先级（重复度>60%）

1. **乱世势力 + 东庭**
   - 精简"乱世势力"中东庭部分至100字
   - 保持"东庭"独立词条完整

2. **百炼 + 崩落派 + 崩落战役**
   - 明确三个词条的时间分工
   - 在交界处使用引导链接

3. **乱世群雄 + 各人物独立词条**
   - 精简"乱世群雄"中各人物至50字
   - 为孟遂、文况、毕宣创建独立词条

### 阶段2：中优先级（重复度30-60%）

4. **百家之乱 + 各专项词条**
5. **净明教 + 黎元派 + 司目**
6. **晓朝 + 各诸侯国**

### 阶段3：低优先级（重复度<30%）

7. 人物词条间的交叉引用优化
8. 地理词条中的历史背景精简

## 质量检查清单

优化后的词条应满足：

**集合词条**：
- [ ] 每个子主题摘要在50-200字之间
- [ ] 使用列表形式呈现关键要点
- [ ] 结尾有"详见[[XX]]"引导链接
- [ ] 不包含详细事件经过或对话

**专门词条**：
- [ ] 内容完整，可独立理解
- [ ] 不重复上层集合词条的框架信息
- [ ] 与并列词条通过链接互相引用
- [ ] 包含充足的内链和相关词条

**衔接处理**：
- [ ] 时间分界点清晰
- [ ] 在转折处使用引导链接
- [ ] 避免重复叙述相同段落

---

## 实施原则

1. **保留导航功能**：集合词条仍是重要的导航入口
2. **确保独立可读**：专门词条仍可独立阅读理解
3. **减少冗余信息**：同一信息只在一处详细展开
4. **强化链接网络**：通过链接建立词条间关系

---

## 预期效果

- 减少重复内容约15,000-25,000字（wiki总量的15-18%）
- 提升阅读体验：集合词条更简洁，专门词条更深入
- 强化词条关联：通过链接建立更清晰的知识网络
- 便于维护更新：信息集中在单一词条，修改时无需多处同步
