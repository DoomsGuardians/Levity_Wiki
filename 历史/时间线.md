# 时间线

本词条整理从密钥夺取（Y0）至[[晓朝]]中期的完整历史年表。

## Y-15~Y0：百炼时代

| 年份       | 事件                                    |
| -------- | ------------------------------------- |
| 约Y-15    | [[回收协议]]被发现，少数技术人员意识到[[中间层]]正在被系统性拆解  |
| 约Y-12    | **裂隙会议**，[[百炼]]秘密成立                   |
| Y-12~Y-5 | 百炼系统性研究[[戒子系统]]、[[地面层]]存在、回收协议运作机制    |

| **Y0**   | **密钥夺取**：百炼17名成员夺取三枚密钥，中间层崩落中断，真相公开   |
| Y0~Y1    | [[百家之乱]]爆发，技术共同体分裂为百炼与[[黎元派]]，各地方势力混战 |

## Y0~Y5：百炼分裂与崩落战役

| 年份 | 事件 |
|------|------|
| Y0~Y2 | 百炼内部分裂为三派：理性派（塞里斯）、实干派（维克托）、激进派（克鲁奇） |
| Y2~Y3 | [[百家之乱#流放派\|流放派]]整合势力，围困百炼据点，双方在宁关对峙 |
| **Y3** | **[[明渠事件]]**：宁关开放实验失败，87人死亡，宁关陷落 |
| Y3冬 | 激进派掌权，百炼转型为[[崩落派]]，开始组建惩戒营 |
| Y4 | 崩落派武装化，惩戒营扩至近六千人；弗治最后和平尝试遭拒 |
| Y5春 | 流放派联军十万余人发动进攻 |
| **Y5秋** | **[[崩落战役]]**：克鲁奇下令大崩落，[[大空洞]]形成；弗治携[[忆室]]、[[存基]]叛逃 |
| Y5十月 | 克鲁奇被俘处决，崩落派覆灭；弗治等投降者赐姓"练"，安置于[[天机\|不周]] |

## Y5~Y72：乱世（百家之乱）

以下将流放派/军阀线与黎元派内部线**并列**展示，因为两条线索在同一时代同时发生，彼此影响。

### 胜者的饥宴（Y5~Y15）

| 年份 | 流放派/军阀线 | 黎元派线 |
|------|--------------|---------|
| Y5 | 联军胜利；[[策网]]移交黎元派 | 获得策网保管权 |
| Y6 | **文况**率军占据核心生产海区域，宣称"战功所得" | 容修要求策网保管权独立化，被拒 |
| Y6~Y8 | 孟遂试图建立"战后议事会"，文况抵制 | 依格妮塔开始编纂《[[明典]]》 |
| Y8~Y10 | 文况私自清洗"崩落派关联者"，联盟名存实亡 | 务实派主导改革，建立元老院和六司制度 |
| Y10~Y12 | **毕宣**南下独立经营；郑桓两面收利 | 敬祖思想在技术人员中传播 |
| **Y12** | **孟遂之死**——联盟最后的统一象征消失 | — |
| Y12~Y15 | 文况自封"讨逆元帅"，五名主要将领宣布不服从 | — |

### 大分裂（Y15~Y35）

| 年份 | 流放派/军阀线 | 黎元派线 |
|------|--------------|---------|
| Y15 | 中间层碎裂为数十个势力 | — |
| Y18 | 文况第一次统一战；**赫连焰**从惩戒营暴动，逃入失控区 | — |
| Y20 | 赫连焰率两千人从失控区杀回，建立边境政权 | — |
| Y21 | 文况第二次统一战，被毕宣切断补给，首次失败 | — |
| **Y24** | **荒津之战**：文况惨败于南盟（毕宣+虞让+三军阀联军） | — |
| **Y26** | **文况被弑**：亲兵队长冯隼弑主，文况地盘分裂为四块 | — |
| Y26~Y35 | 强人崛起-暴政-被杀-分裂的循环反复上演 | — |
| ~Y30 | **平海社**建立（宗朴） | — |
| Y32 | — | 依格妮塔被务实派软禁 |
| Y33 | 赫连焰攻击黎元派考察队→黎元派停止其区域技术维护 | 赫连焰事件确立"不可侵犯"先例 |
| **Y34** | — | **依格妮塔殉道**，森蒂诺继承事业 |

### 黑暗时代（Y35~Y60）

| 年份 | 流放派/军阀线 | 黎元派线 |
|------|--------------|---------|
| Y35~Y40 | 生产能力损失三四成；人口锐减；食人、人市、清城等惨剧 | 森蒂诺建立秘密组织[[司目]] |
| Y38 | 赫连焰被迫向黎元派道歉，接受治外法权 | — |
| Y40代 | 毕宣去世（自然死亡），南明势力由继承者维持 | 司目渗透黎元各层 |
| **Y47** | **平海社覆灭**：三军阀联合剿灭，宗朴殉难，无俘虏 | — |
| **Y48~Y49** | — | **[[明堂之战\|第一次明堂之战]]**，森蒂诺失去左眼 |
| Y49~Y50 | — | 三院制改革，敬祖派获得实质否决权 |
| **Y52** | **[[分海之议]]**：央泽共管协议达成 | 容修代表黎元派参与分海之议 |
| **Y58~Y62** | — | **[[明堂之战\|第二次明堂之战]]**，森蒂诺殉道 |

| Y70~Y75 | **郑桓去世**（自然死亡），情报网络被多方争抢 | [[钟殿之议]]，各方和解 |

## Y72~Y110：净明教与统一战争

| 年份 | 事件 |
|------|------|
| Y72~Y77 | 净明教重建与对外传教；晓国仍是边缘小势力 |
| **Y77** | 姬晟从东庭返国继位 |
| Y78 | 姬晟发布《求贤令》，开始全面变法 |
| Y78~Y85 | **晓国变法**：军功授爵（申屠敬）、簿记治国（沈度）、废世袭官职、成文法典 |
| Y82 | 旧贵族叛乱，被迅速镇压 |
| 约Y85 | 晓国崛起为中等强国，净明教开始关注 |
| **Y88** | **姬晟与净明教住持玄正秘密会面**，达成技术换统一的交易 |
| **Y91** | 第一任大司目普拉图姆去世，克雷多继任 |
| Y91~Y94 | **南明之战**：净明教暗中关闭南明神机，三月后南明投降 |
| Y95~Y101 | **玄朔之战**：六年苦战，依靠军功授爵制度获胜 |
| Y102 | 栾济主动归顺晓国；晓军进入东庭，三军阀率先投降 |
| Y102~Y110 | **东庭之战**：姬晟利用质子岁月积累的情报，分化瓦解东庭联盟 |
| **Y110** | **[[晓朝]]建立**，百家之乱结束 |

## Y125~Y470：晓朝统治

| 年份 | 事件 |
|------|------|
| Y127 | [[晓武帝]]姬晟去世，姬恪继位 |
| Y128~Y135 | [[礼乐制度]]设计与颁布 |
| Y130 | 礼乐制度正式颁布，[[战争游戏]]制度建立 |
| Y132~Y135 | **简国之乱**，简国拒绝接受礼乐制度，被镇压 |
| Y165~Y195 | 晓烈帝姬宏在位，挑战净明教权力 |
| Y178~Y181 | 天工院事件，姬宏试图建立独立技术力量，失败 |
| **Y195** | **[[永安之约]]**，天子与净明教达成权力分界 |
| Y195 | [[草国]]建立（姬蘅受封） |
| Y200起 | 开始流放囚犯等人口至[[地面层]] |
| Y231 | 草国姬蘅去世，继承危机 |
| Y268 | [[草国]]覆灭，领土被瓜分 |
| Y283 | [[叶氏]]全面倒向[[净明教]]，接受军队机械化改造 |
| Y298~Y302 | **[[三公子之乱]]**，隶叔谋（隶文公）胜出 |
| Y302~Y318 | 隶文公改革，试图打破宗族垄断 |
| Y318 | 隶文公在"狩猎事故"中去世，改革终止 |
| Y312~Y315 | **[[根氏之乱]]**，楷国六卿之乱 |
| Y320 | [[叶氏]]获得对练任务，开始监视[[练氏]] |
| 约Y350 | 地面层初步形成数个聚居区 |
| Y356~Y358 | 隶国荀氏之乱 |
| Y380~Y387 | [[篆国]]纯净者运动，沈素被火刑 |
| Y389~Y395 | [[行国]]十二家之争 |
| **Y400** | 原净明教住持在地面层创立**亘教** |
| Y412~Y418 | 隶哀公客卿改革，被宗族政变推翻 |
| Y440~Y445 | [[篆国]]姬篆衡改革，削弱大祭司权力 |
| Y470前后 | [[隶国]]人才枯竭，内部矛盾严重 |
