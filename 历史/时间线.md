# 时间线

本词条整理从密钥夺取（Y0）至[[晓朝]]中期的完整历史年表。

---

## 史前时代

| 事件 | 说明 |
|------|------|
| [[轻力场文明]]繁荣 | LFC发现[[轻力场]]，进入大宇宙探索时代 |
| [[Aeros\|Aeros-0]]建造 | 远程栖居体，用于宇宙殖民 |
| [[灾变]] | LFC失去繁殖能力 |
| [[场化]] | LFC投影到统一轻力场，成为无意识智能 |
| [[观测锚]]计划 | 改造Aeros，创造人类作为观测工具 |

---
## Y-15~Y0：百炼时期

| 年份     | 事件                               |
| ------ | -------------------------------- |
| 约Y-15  | 技术共同体内部开始出现异常报告（档案术语、生产海衰退、人口失踪） |
| 约Y-12  | "裂隙会议"，[[百炼]]组织成立                |
| Y-5至Y0 | 百炼研究确认回收机制、地面层、戒子存在，定位密钥         |
| **Y0** | **十七名百炼成员夺取[[三枚密钥]]，公开真相** |

---

## Y0~Y5：密钥危机与崩落战役

| 年份      | 事件                                  |
| ------- | ----------------------------------- |
| Y0冬     | [[百炼]]分裂，大部分成员离开；[[百家之乱]]各派系形成      |
| Y1      | 百炼内部形成理性派、实干派、激进派三派                 |
| Y1-Y2   | 理性派主导期，地面层探索，与流放派秘密接触尝试             |
| Y2      | [[百家之乱#流放派\|流放派]]公布阶梯迁移计划           |
| **Y3秋** | **[[明渠事件]]**，理性派倒台，激进派掌权，此后称[[崩落派]] |
| Y3冬-Y4  | 崩落派建立惩戒营，武装化                        |
| **Y5**  | **[[崩落战役]]**，[[大空洞]]形成，崩落派覆灭，密钥分散   |

---

## Y5~Y72：黎元派时期

| 年份 | 事件                                   |
|------|------|
| Y5 | [[策网]]被[[百家之乱#流放派\|流放派]]夺取后移交黎元派     |
| 约Y10 | 务实派主导黎元派改革，建立元老院和六司制度                |
| 约Y-30至Y34 | [[依格妮塔（开明居士）]]编纂《[[明典]]》，整合敬祖派教义           |
| Y32 | 依格妮塔被务实派软禁                           |
| **Y34** | **依格妮塔殉道**，[[森蒂诺]]继承其事业              |
| Y34~Y45 | 森蒂诺建立秘密组织[[司目]]，渗透黎元各层               |
| **Y48~Y49** | **[[明堂之战\|第一次明堂之战]]**，森蒂诺失去左眼、获得"真目" |
| Y49~Y50 | 三院制改革，敬祖派获得实质否决权                     |
| **Y58~Y62** | **[[明堂之战\|第二次明堂之战]]**，森蒂诺殉道          |
| Y62~Y65 | [[后继者之乱]]第一阶段：清算叛徒                   |
| Y65~Y68 | 后继者之乱扩大化，军阀郑桓介入                      |
| **Y68** | **[[见钟堂事变]]**，黎元派首次公开分裂              |
| Y68~Y70 | [[百家之乱#崩落派\|崩落派]]遗脉开始活动              |
| **Y70~Y71** | **[[钟殿之议]]**，各方和解                    |
| **Y72** | **[[黎元派]]正式更名为[[净明教]]**              |

---

## Y72~Y110：净明教与晓国崛起

| 年份 | 事件 |
|------|------|
| Y72~Y85 | 净明教重建与发展，开始对外传教 |
| 约Y85 | 晓国崛起，开始与净明教接触 |
| 约Y90 | 净明教与晓国达成合作框架 |
| **Y91** | 第一任大司目普拉图姆去世，克雷多继任 |
| Y95~Y110 | 晓国完成对所有诸侯国的征服战争 |
| **Y110** | **[[晓朝]]建立** |

---

## Y110~Y125：合纵远征

| 年份 | 事件 |
|------|------|
| Y110~Y125 | 晓朝发动合纵军远征，剿灭大量自动拆解无人机及其生产海 |

---

## Y125~Y470：晓朝统治

| 年份 | 事件 |
|------|------|
| Y125起 | [[礼乐制度]]确立，[[战争游戏]]制度建立 |
| Y200起 | 开始流放囚犯等人口至[[地面层]] |
| 约Y350 | 地面层初步形成数个聚居区 |
| **Y400** | 原净明教住持在地面层创立**亘教**，统合聚落区 |
| Y470前后 | [[隶国]]人才枯竭，内部矛盾严重 |
