# 时间线

本词条整理从密钥夺取（Y0）至[[晓朝]]中期的完整历史年表。

---

## 史前时代

| 事件 | 说明 |
|------|------|
| [[轻力场文明]]繁荣 | LFC发现[[轻力场]]，进入大宇宙探索时代 |
| [[Aeros\|Aeros-0]]建造 | 远程栖居体，用于宇宙殖民 |
| [[灾变]] | LFC失去繁殖能力 |
| [[场化]] | LFC投影到统一轻力场，成为无意识智能 |
| [[观测锚]]计划 | 改造Aeros，创造人类作为观测工具 |

---

## Y-15~Y0：百炼时代

| 年份 | 事件 |
|------|------|
| 约Y-15 | [[回收协议]]被发现，少数技术人员意识到[[中间层]]正在被系统性拆解 |
| 约Y-12 | **裂隙会议**，[[百炼]]秘密成立 |
| Y-12~Y-5 | 百炼系统性研究[[戒子系统]]、[[地面层]]存在、回收协议运作机制 |
| 约Y-5 | 百炼发现[[三枚密钥]]可以中断回收协议 |
| **Y0** | **密钥夺取**：百炼17名成员夺取三枚密钥，中间层崩落中断，真相公开 |
| Y0~Y1 | [[百家之乱]]爆发，技术共同体分裂为百炼与[[黎元派]]，各地方势力混战 |

---

## Y0~Y5：百炼分裂与崩落战役

| 年份 | 事件 |
|------|------|
| Y0~Y2 | 百炼内部分裂为三派：理性派（塞里斯）、实干派（维克托）、激进派（克鲁奇） |
| Y2~Y3 | [[百家之乱#流放派\|流放派]]整合势力，围困百炼据点，双方在宁关对峙 |
| **Y3** | **[[明渠事件]]**：宁关开放实验失败，87人死亡，宁关陷落 |
| Y3冬 | 激进派掌权，百炼转型为[[崩落派]]，开始组建惩戒营 |
| Y4 | 崩落派武装化，惩戒营扩至近六千人；弗治最后和平尝试遭拒 |
| Y5春 | 流放派联军十万余人发动进攻 |
| **Y5秋** | **[[崩落战役]]**：克鲁奇下令大崩落，[[大空洞]]形成；弗治携[[忆室]]、[[存基]]叛逃 |
| Y5十月 | 克鲁奇被俘处决，崩落派覆灭；弗治等投降者赐姓"练"，安置于[[天机\|不周]] |

---

## Y5~Y72：黎元派时期

| 年份 | 事件 |
|------|------|
| Y5 | [[策网]]被[[百家之乱#流放派\|流放派]]夺取后移交黎元派 |
| 约Y10 | 务实派主导黎元派改革，建立元老院和六司制度 |
| 约Y10至Y34 | [[依格妮塔（开明居士)]]编纂《[[明典]]》，整合敬祖派教义 |
| Y32 | 依格妮塔被务实派软禁 |
| **Y34** | **依格妮塔殉道**，[[森蒂诺]]继承其事业 |
| Y34~Y45 | 森蒂诺建立秘密组织[[司目]]，渗透黎元各层 |
| **Y48~Y49** | **[[明堂之战\|第一次明堂之战]]**，森蒂诺失去左眼、获得"真目" |
| Y49~Y50 | 三院制改革，敬祖派获得实质否决权 |
| **Y58~Y62** | **[[明堂之战\|第二次明堂之战]]**，森蒂诺殉道 |
| Y62~Y65 | [[后继者之乱]]第一阶段：清算叛徒 |
| Y65~Y68 | 后继者之乱扩大化，军阀郑桓介入 |
| **Y68** | **[[见钟堂事变]]**，黎元派首次公开分裂 |
| Y68~Y70 | [[百家之乱#崩落派\|崩落派]]遗脉开始活动 |
| **Y70~Y71** | **[[钟殿之议]]**，各方和解 |
| **Y72** | **[[黎元派]]正式更名为[[净明教]]** |

---

## Y72~Y110：净明教与晓国崛起

| 年份 | 事件 |
|------|------|
| Y72~Y85 | 净明教重建与发展，开始对外传教 |
| 约Y85 | 晓国崛起，开始与净明教接触 |
| Y88 | 姬晟与净明教住持玄正秘密会面，达成合作协议 |
| **Y91** | 第一任大司目普拉图姆去世，克雷多继任 |
| Y91~Y94 | **南明之战**，晓国首次使用[[策网]]作战，南明投降 |
| Y95~Y101 | **玄朔之战**，依靠军功授爵制度激发的战斗力获胜 |
| Y102~Y110 | **东庭之战**，姬晟利用质子岁月积累的情报分化瓦解 |
| **Y110** | **[[晓朝]]建立** |

---

| 年份 | 事件 |
|------|------|
| Y111 | [[晓武帝]]召集诸侯会盟 |
| Y112~Y116 | [[合纵远征]]第一阶段：边境扫荡 |

## Y125~Y470：晓朝统治

| 年份 | 事件 |
|------|------|
| Y127 | [[晓武帝]]姬晟去世，姬恪继位 |
| Y128~Y135 | [[礼乐制度]]设计与颁布 |
| Y130 | 礼乐制度正式颁布，[[战争游戏]]制度建立 |
| Y132~Y135 | **简国之乱**，简国拒绝接受礼乐制度，被镇压 |
| Y165~Y195 | 晓烈帝姬宏在位，挑战净明教权力 |
| Y178~Y181 | 天工院事件，姬宏试图建立独立技术力量，失败 |
| **Y195** | **[[永安之约]]**，天子与净明教达成权力分界 |
| Y195 | [[草国]]建立（姬蘅受封） |
| Y200起 | 开始流放囚犯等人口至[[地面层]] |
| Y231 | 草国姬蘅去世，继承危机 |
| Y268 | [[草国]]覆灭，领土被瓜分 |
| Y283 | [[叶氏]]全面倒向[[净明教]]，接受军队机械化改造 |
| Y298~Y302 | **[[三公子之乱]]**，隶叔谋（隶文公）胜出 |
| Y302~Y318 | 隶文公改革，试图打破宗族垄断 |
| Y318 | 隶文公在"狩猎事故"中去世，改革终止 |
| Y312~Y315 | **[[根氏之乱]]**，楷国六卿之乱 |
| Y320 | [[叶氏]]获得对练任务，开始监视[[练氏]] |
| 约Y350 | 地面层初步形成数个聚居区 |
| Y356~Y358 | 隶国荀氏之乱 |
| Y380~Y387 | [[篆国]]纯净者运动，沈素被火刑 |
| Y389~Y395 | [[行国]]十二家之争 |
| **Y400** | 原净明教住持在地面层创立**亘教** |
| Y412~Y418 | 隶哀公客卿改革，被宗族政变推翻 |
| Y440~Y445 | [[篆国]]姬篆衡改革，削弱大祭司权力 |
| Y470前后 | [[隶国]]人才枯竭，内部矛盾严重 |
