# 03-社会制度

本目录包含Aeros人类社会的政治制度、宗教组织和文化概念。

这些制度既是权力运作的工具，也是应对资源限制和人口压力的系统性解决方案。

---

## 政治制度

晓朝的核心政治制度，由净明教通过戒子计算设计。

- [[礼乐制度]] - 晓朝的分封与继承制度
  - 嫡长子继承制：天子→诸侯→卿大夫→士
  - 阶级膨胀问题：非嫡子降级导致贵族数量指数增长
  - 战争礼仪：不杀贵族、投降赎买、生产海禁战区

- [[战争游戏]] - 周期性战争与人口控制
  - 本质：通过制度化战争消耗膨胀的人口
  - 规则：限制规模、禁止灭国、保护贵族
  - 矛盾：人道主义外表下的冷酷计算

- [[人口与行政]] - 晓朝人口规模、行政区划与社会阶层
  - 人口规模：约1500-2000万
  - 行政层级：司天省 → 诸侯国 → 州 → 城
  - 社会阶层：天子、诸侯、卿大夫、士、庶民
  - 货币体系：筹、实物流通、筹契

**核心逻辑**: 礼乐制度制造问题（人口膨胀），战争游戏解决问题（人口消耗）

## 文化概念

其他重要的文化和社会概念。

- [[方位体系]] - Aeros内部的方向与定位
  - 圆柱体内没有传统的东西南北
  - 基于轴向(spinward/anti-spinward)和径向(inward/outward)
  - 影响语言、建筑、战术思维

- [[惩戒营]] - 百炼/崩落派的特殊兵种
  - 起源：崩落派强制征召的囚犯部队
  - 特点：高死亡率任务、极端纪律、自我牺牲文化
  - 遗产：部分投降者成为练氏家族的武装力量

- [[建筑与城市]] - 中间层的建筑传统与城市形态
  - 金属榫卯建筑体系
  - 净明教建筑美学
  - 诸侯宫殿与民居

- [[饮食文化]] - 生产海食材与烹饪传统
  - 基础食材：膏、醴、脂、盐
  - 发酵与调味
  - 地域菜系

## 制度演化

**乱世前期(Y0~Y35)**
- 无统一制度，各势力自行其是
- 黎元派建立元老院和六司制度
- 同炉坊尝试公社制实验

**乱世后期(Y35~Y110)**
- 黎元派/净明教巩固技术垄断
- 宗教教义系统化（明典编纂）

**晓朝时期(Y110~)**
- Y110-Y130：礼乐制度确立
- Y195：[[永安之约]]划定天子与净明教权力边界
- Y130后：战争游戏制度化
