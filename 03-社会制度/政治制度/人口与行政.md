# 人口与行政

本词条整理[[晓朝]]的人口规模、行政区划与社会结构。

---

## 人口规模

[[晓朝]]控制区总人口约**一千五百万至两千万**。

这一数字受到几个硬性限制：

**生产海产能**：[[生产海]]的食物产出是人口上限的最终约束。Y5年[[大空洞]]形成后，该区域的生产海遭受毁灭性损失。此后五百年间，因战争破坏、缺乏维护和无人机回收，生产海总产能持续缓慢下降——人口上限也随之收缩。

**电网覆盖**：生产海设施依赖超导电网供电。电网的不可逆萎缩意味着边缘区域的生产海逐渐停产，能够供养人口的有效面积在缩小。

**战争消耗**：[[战争游戏]]制度下的周期性战争持续消耗人口，尤其是底层庶民和士阶层。这与[[礼乐制度]]造成的贵族阶级膨胀形成微妙的平衡——战争杀人，但制度生人。

**流放政策**：Y200年起，晓朝系统性地将囚犯、流民和"多余人口"流放至[[地面层]]。数百年累计，大量人口被单向输送到地面层。

## 行政区划

### 层级结构

| 层级 | 单位 | 说明 |
|------|------|------|
| 第一级 | 天子直辖区（司天省） | 天子驻地，净明教目枢所在 |
| 第二级 | 诸侯国 | 约十五至二十个，规模差异极大 |
| 第三级 | 州 | 诸侯国下辖，约三十至四十个 |
| 第四级 | 城 | 州的核心聚居点 |

### 州

州是晓朝行政体系的基本单元。一个州至少包含**一座城**和**配套的一片生产海**——这是州存在的最低条件，因为一座没有生产海的城无法自给。

| 项目 | 平均值 | 波动范围 |
|------|--------|---------|
| 面积 | 约700平方公里 | 200-2000平方公里 |
| 人口 | 约50万 | 10万-150万 |
| 城市数量 | 1-3座 | 边缘州可能只有一座小城 |
| 生产海覆盖 | 约占州面积70-80% | 视生产海保存状况而定 |

州的规模浮动极大——楷国核心州可能拥有百万以上人口和多座城市，而边境小州可能只有十几万人和一座小城堡。

### 诸侯国

晓朝建立时分封了约十五至二十个诸侯国。故事中着重涉及的六国是规模和影响力最大的几个：

| 诸侯国 | 类型 | 州数（估计） | 人口（估计） |
|--------|------|-------------|-------------|
| [[楷国]] | 最强姬姓大国 | 十三州 | 约400-500万 |
| [[隶国]] | 老牌他姓强国 | 八至十州 | 约250-350万 |
| [[燧国]] | 边境军事强国 | 五至七州 | 约150-200万 |
| [[篆国]] | 半神权国 | 四至六州 | 约100-180万 |
| [[行国]] | 商业国 | 三至五州 | 约80-150万 |
| [[草国]] | 已覆灭 | 曾辖二至三州 | — |

其余十个左右的中小诸侯国各辖一至三州，人口数十万级别。这些小国在大国之间求存，是战争游戏中最脆弱的参与者——一场失利可能就丢掉唯一的州。

### 司天省

天子直辖区，名义上不属于任何诸侯国。净明教[[目枢]]、天子朝廷、中央官署均设于此。司天省的生产海由净明教直接管理。

## 社会阶层

### 阶层结构

| 阶层    | 占比（估计）     | 说明         |
| ----- | ---------- | ---------- |
| 天子    | 1人         | 晓朝最高统治者    |
| 诸侯    | 十余家        | 诸侯国领主及其直系  |
| 卿大夫   | 约数百家       | 诸侯下属领地领主   |
| 士     | 约占总人口1-2%  | 最低级贵族，有姓无地 |
| 庶民    | 约占总人口95%以上 | 无贵族身份的普通人  |
| 净明教教阶 | 独立于世俗阶层    | 从瞻士到住持     |

### 士阶层

士是[[礼乐制度]]不断产生的"过剩贵族"——卿大夫的非嫡子降为士，士的非嫡子降为庶民。每一代都有大量新士产生，同时也有大量旧士后代跌入庶民。士拥有姓氏、受过教育、通常习武，但没有领地和稳定收入。

#### 出路分化

**仕途**：给诸侯或卿大夫当家臣、幕僚、军官。最体面但竞争最激烈——需要才能、关系或两者兼备。

**军功**：在[[战争游戏]]中立功可获"复爵"——被有权势的卿大夫收为附庸，授予小片领地。这条路极其险窄——士在战场上的死亡率远高于卿大夫嫡系——但它是底层唯一的上升通道。

**技术**：通过[[机缘]]测试进入[[净明教]]体系。净明教是唯一不完全按血统录用的组织——机缘测试不看出身。对很多士家子弟来说，这是改变命运的捷径。

**商贸**：在[[行国]]等商业发达地区经商。贵族经商在礼制中被视为"失体统"，但在行国这种观念较淡。许多士经商后积累了可观的财富，虽然社会地位并不因此提升。

**拾荒**：组建或加入拾荒队，深入失控区搏命换富贵。一枚品相完好的[[蓄器]]可以改变一个士的命运。但拾荒的死亡率也足以说明这条路的代价。

**游士**：在诸侯国之间游走，出卖专业技能——军事教官、情报贩子、纂术师、蚀刻工匠等。战争游戏时受雇参战，平时靠手艺维生。游士群体是文化和技术跨区域传播的重要载体。

**流民化**：最惨的结局。降为庶民后无产无业，在战争游戏中被征为炮灰，或被流放[[地面层]]。

#### 士与庶民的上升渠道

[[晓武帝]]建国时推行军功授爵制，但晓朝建立后被[[礼乐制度]]的血统制大幅限制。保留的版本是：

- 庶民可通过军功升为士（极难，需要显赫战功）
- 士可通过军功获得卿大夫的附庸地位（难但可能）
- 士或庶民不可能通过军功直接成为独立的卿大夫（必须被现有卿大夫"收养"或"举荐"）

这个设计既给底层留了一个极窄的希望，又确保世袭贵族的根本利益不受威胁。

### 庶民

占人口绝大多数。庶民没有姓氏（只有名），没有受教育的制度性保障，没有战争中的保护条款。

庶民的职业涵盖：生产海维护工（在神机指导下执行基础维护，不涉及核心技术）、工匠（金属加工、蚀刻、烹饪）、搬运工和轨道工（货运系统的人力环节）、市集商贩、酒肆店家、拾荒队搬运工等。

## 货币体系

### 筹

晓朝的基本记账单位——**筹**。一筹等于一个标准生产海模块一个周期的标准产出。筹不是实物货币，而是配额单位——诸侯国的岁入、贡赋、赎金、延战金等大额交易都以筹计算。

### 实物流通

日常小额交易使用**死质金属铸币**。铸币由各诸侯国铸造，以重量标准化，互相通用——毕竟原料都一样，只是形状和铭文不同。行国的灰线商盟铸造的"行钱"因成色统一而信誉最好，是事实上的通用货币。

### 筹契

大额交易使用**筹契**——类似汇票的书面凭证，由灰线商盟或诸侯国官府背书，承诺在指定生产海兑付一定量的实物产出。筹契的流通和背书体系是[[行国]]金融影响力的核心。
