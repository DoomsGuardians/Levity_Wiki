# 02-技术体系

本目录包含人类在Aeros中发展的技术体系，包括炼术理论、军事技术、工具设备和经济资源系统。

所有技术的核心特征是**混血性**：核心组件来自LFC遗物（不可制造，只能回收），人类负责框架和应用层面的创新。

---

## 炼术理论

**百炼六条根**技术理论体系，是人类理解和操纵LFC技术的基础。

- [[炼术]] - 完整的六条根技术体系
  - 克鲁奇·断域 - 结构分析与破坏
  - 容修·图脉 - 系统拓扑与流量控制
  - 塞里斯·静听 - 被动监听与环境感知
  - 维克托·纂令 - 信息编码与通讯
  - 弗治·治器 - 工具改造与设备操作
  - 阿尔戈·联结 - 系统集成（理论存疑）

**推荐阅读**: 先读完整的炼术词条，再结合军事技术理解具体应用

## 军事技术

战争中使用的具体技术手段，每一项都可追溯到炼术的理论来源。

- [[军事技术]] - 完整的军事技术体系词条，包括：
  - 通讯体系：寄生通讯、拟噪通讯、跳频通讯、镜语
  - 电探与电子战：照射、被动监听、干扰、惑影、隐目/照目
  - 管路战：渗透、监听、管噪对抗
  - 大气操控：渐窒、烈风
  - 生物技术武器：萤引、蚀种、嗅犬
  - 战争机械：装甲列车、陆行舰、动力装甲、炼器
  - 航空战力：动力源限制、机型、蜮（无人机）
  - 壁中城与结构战：壁中城、塌方战术
  - 纂术与计算：火控解算、密码学、后勤计算

**特点**: 这是只有在人造封闭环境中才会出现的战争形态

## 工具与设备

核心设备与工具。

- [[蓄器]] - LFC储能组件，不可再生但可缓慢回充
  - 所有脱离电网的机动设备（飞机、装甲）都依赖蓄器
  - 回充效率极低，持续劣化
  - 一国的机动能力等于其蓄器库存

## 经济与资源

技术体系背后的经济基础。

- [[回收经济]] - 核心组件只能回收不能制造的经济模式
  - 拾荒产业链：探索失控区 → 回收组件 → 修复 → 分配
  - 资源枯竭威胁：破坏速度超过回收速度
  - 战略垄断：[[行国]]控制能量单元贸易
  - 技术垄断：[[净明教]]和[[练氏]]控制精密组件生产

**核心矛盾**: 人类文明建立在不可再生资源之上，战争在加速资源消耗
