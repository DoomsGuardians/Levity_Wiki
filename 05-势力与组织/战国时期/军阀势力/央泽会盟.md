# 央泽会盟

**央泽会盟**（Y53-Y68）是[[百家之乱]]中由[[虞让]]与[[方吾庐]]建立的跨势力协商机构，试图以制度约束权力、以谈判取代战争。会盟在鼎盛时期成功调解了多起纠纷，但最终因缺乏强制力，随虞让之死而瓦解。

---

## 起源

Y52年[[分海之议]]的成功证明"谈判是可能的"。方吾庐认为这不应是一次性事件，而应制度化。他说服虞让在央泽共管区建立常设议事机构。

方吾庐的核心理念是：*"需要制度而非道德——好的制度假设所有人都可能作恶，然后设计出让作恶代价高昂的机制。"*

但他面临的根本困境是：议会没有自己的武力，只能依赖虞让的军事保护。

---

## 各方代表

央泽会盟名义上有六方代表，但各方派来的人选本身就说明态度：

| 势力       | 代表               | 实际态度           |
| -------- | ---------------- | -------------- |
| 虞让       | **季宁**（幕僚长）      | 最认真，给予较大授权     |
| [[东庭]]   | 退休军阀             | 敷衍，把会盟当养老院     |
| [[南津]]   | 商会代表             | 只关心贸易，政治议题一律弃权 |
| [[栾国]]   | 栾崇诸子轮流           | 当练兵场，培养继承人     |
| [[灰线商盟]] | **马信**（[[郑桓]]心腹） | 表面中立，实际收集情报    |
| [[玄朔]]   | 不常驻              | 仅涉及边境问题时临时参加   |

Y45年[[铁契]]瓦解后，[[沈青]]率残部投奔虞让。Y53年会盟建立时，沈青成为虞让代表团成员。他的经历——亲眼见证"人质制度"从善意变成恐怖——给了方吾庐重要启发。

## 运作历程

### 上升期（Y53-55）

会盟成功调解了两起边境纠纷，各方开始认真对待。

### 巩固期（Y56-58）

建立了央泽共管区的详细规则，贸易纠纷有了仲裁机制。

Y55年，沈青在会盟提出"惩罚机制"——如果某方违反会盟决议，其他各方应共同制裁。提案被否决——没有人想约束自己。

### 危机期（Y58-62）

[[明堂之战|第二次明堂之战]]爆发。会盟试图调停[[黎元派]]内斗，被黎元派拒绝。各方代表私下评论：*"连黎元派的事都管不了，这会盟有什么用？"*

### 名存实亡期（Y62-65）

各方代表仍然开会，但不再执行决议。会盟实际上变成了情报交换场所。

### 崩溃（Y66-68）

Y66年虞让病重，东庭开始蚕食其地盘。其他势力在会盟上谴责东庭，但没有人愿意为虞让出兵。

Y68年虞让死，其子虞衡试图抵抗，但手下将领纷纷投靠东庭。会盟正式解散。

---

## 核心人物的结局

- **方吾庐**：流亡[[栾国]]，晚年著书。其理论影响了栾国的"六卿制"实验，但著作被[[晓朝]]列为禁书。
- **沈青**：虞让死后隐居，拒绝参与任何一方，此后下落不明。
- **季宁**：随虞衡抵抗失败，可能战死或被俘。
- **马信**：东庭进攻时提前撤离，返回灰线商盟。

---

## 历史意义

央泽会盟是乱世中"以制度约束权力"的最认真尝试。它的失败不是因为理念错误，而是因为**制度本身需要权力来维护**。

方吾庐晚年反思：*"我以为制度可以约束权力，却忘了制度本身需要权力来维护。没有剑的法律，只是一张纸。"*

[[晓朝]][[礼乐制度]]中"生产海禁战"条款参考了方吾庐的理念，但他的著作被列为禁书——"谁有权统治"对任何统治者都是危险问题。
