# 05-势力与组织

本目录按时期和性质组织各类政治势力、军事组织和社会团体。

---

## 战国时期势力 (Y0~Y110)

密钥夺取后到晓朝建立前的百年乱世，各方势力围绕密钥控制权和生产海资源展开争夺。

### 百炼系

密钥夺取的核心组织及其分裂后的派系。

- [[百炼]] - Y-12成立的技术人员秘密组织，密钥夺取的执行者
  - 理性派：主张开放技术、建立民主制度（Y3明渠事件覆灭）
  - 实干派：技术官僚路线，后成为黎元派核心
  - 激进派：武力统一路线，后转型为崩落派
- [[崩落派]] - 百炼激进化后的武装力量，Y5崩落战役后覆灭
- [[流放派]] - 围困百炼的多方联盟，松散组织

### 黎元派系

技术官僚组织，净明教前身。

- [[黎元派]] - 百炼实干派为核心建立的技术官僚组织
  - 掌握策网密钥
  - 建立元老院和六司制度
  - Y35~Y72经历内部清洗（后继者之乱）
  - Y72转型为净明教

### 军阀势力

割据一方的军事政治势力。

- [[东庭]] - 东部大势力
- [[南津]] - 南部商业势力
- [[玄朔]] - 北方军阀
- [[栾国]] - 栾氏兄弟建立的国家
- [[晓国]] - 晓武帝建立前的势力基础
- [[灰线商盟]] - 商业联盟
- [[央泽会盟]] - 议会制政体实验
- [[执筹]] - 签约联盟
- [[铁契]] - 军事同盟

### 其他势力

不属于上述分类的特殊组织。

- [[同炉坊]] (Y30~Y47) - 宗朴建立的工匠公社，主张"生产海属于耕者"
- [[守典祠]] - 其他组织

---

## 晓朝时期势力 (Y110~)

晓朝建立后的政治格局。

### 中央

- [[晓朝]] - 统一中间层的王朝，姬氏天子世袭
  - 建立者：[[晓武帝]]姬晟 (Y110)
  - 礼乐制度确立：[[晓文帝]]姬恪
  - 核心矛盾：天子与净明教的权力边界（Y195永安之约）

### 诸侯国

分封制下的诸侯国，按姓氏、实力、特色分类。

**姬姓诸侯（天子同姓）**
- [[楷国]] - 最强姬姓诸侯国，六卿制度，[[叶氏]]、[[颜氏]]等卿大夫

**他姓诸侯**
- [[隶国]] - 老牌强国，三公子之乱
- [[燧国]] - 边境军事强国，"双盲"战术专家
- [[篆国]] - 半神权诸侯国，净明教影响力强
- [[草国]] - 短命的理想主义实验
- [[行国]] - 商业诸侯国，垄断拾荒贸易和能量单元

### 学派组织

- [[篆学派]] - 晓朝学派

## 跨时期组织

跨越战国和晓朝两个时期的组织。

### 净明教

技术官僚宗教组织，从黎元派转型而来(Y72)，持续至晓朝时期。

- [[净明教]] - 总述
- [[司目]] - 敬祖派秘密组织，净明教核心权力机构前身
- [[目枢]] - 净明教最高权力机构
- 相关经典：[[明典]]、[[机缘]]（见 [03-社会制度](../03-社会制度/)）

**权力基础**:
- 掌握策网密钥
- 垄断技术人才培养
- 控制所有神机和生产海维护

### 练氏家族

虽然练氏主要在 [06-人物与家族](../06-人物与家族/家族/) 中记录，但作为掌握两枚密钥的特殊组织，在势力层面也值得关注。

- 起源：Y5崩落派投降者，[[练铸]]为始祖
- 职责：守护忆室和存基密钥
- 根据地：[[天机]]（极致的壁中城）
- 角色：囚徒、守门人、技术垄断者之一

## 势力演化图

```
Y0: 密钥夺取
    ↓
Y0~Y5: 百炼分裂
    ├─→ 理性派 (Y3明渠事件覆灭)
    ├─→ 实干派 → 黎元派 → 净明教
    └─→ 激进派 → 崩落派 (Y5覆灭) → 练氏(投降者)

Y5~Y110: 军阀混战
    各方势力争夺生产海

Y110: 晓武帝统一 → 晓朝建立
    ├─→ 中央（天子）
    ├─→ 诸侯国
    └─→ 净明教（技术垄断）
```
