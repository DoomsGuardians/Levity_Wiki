## 2026年6月更新：楷国疆域落地（基质首个实例）

### 更新日期
2026年6月8日

### 更新概述
用[[舆图基质]]的三问尺子（财富哪来／靠什么关守／哪场战争冻结）把抽象框架落到[[楷国]]十三州的具体疆界上，验证基质能反推既有政治结构。新建[[楷国疆域]]词条。

### 锁定要点
- **区位骨架**：楷国＝中央肥海盆地 + 一圈饥饿关隘环。五区位＝①中央生产海盆地（颜/榛/楷君，财富无险）②叶氏关隘环（北脊巨梁/南脊管沟，险而无粮）③东咽喉天机（练氏，有路无粮的囚徒）④西北缺口（顶无人机的衰退锋）⑤东南坟唇（根氏边缘州，近矿远权）。
- **基质反推出的政治成因**：叶颜双峰对峙＝守关者养不起军队×守海者守不住粮仓的地理错位；颜氏走贸易而非武力＝肥而不可守地形的唯一活法；练氏锁东咽喉＝唯一通路×海尽毁的几何判决；根练天然结盟＝同被甩在东缘贫瘠带；六卿无法自立＝配给网断电时地盘本就碎成互不接壤的光岛，姬桦只是盖章冻结。
- **方位修正（正典更正）**：[[天机]]旧词条"楷国西侧边缘"有误，校准为**东侧边缘**（楷隶之界、大空洞北唇），与[[晓朝舆图]]"自西向东＝楷—天机—隶"几何一致。天机词条正文与基本信息表已同步改正。

### 回接
[[楷国疆域]] 已双向链入 [[楷国]]、[[天机]]、[[晓朝舆图]]、[[舆图基质]]（列为"待扩展"的首个落地实例）。

## 一、轻力场物理体系（已确定）

### 核心定义

**轻力场 = 轴子场 + 信息几何对应关系**

保留"轻力场是轴子场"的原有设定，但增加了信息几何的深层解释：

#### 物理层面（保留）
- 轴子是真实粒子，形成弥漫宇宙的背景场
- 可以形成拓扑缺陷（宇宙弦、畴壁、拓扑结）
- 拓扑缺陷稳定、可工程化操纵
- 与电磁场耦合极弱，几乎不可观测

#### 信息层面（新增）
- 轴子场的拓扑结构 = 信息空间的几何形状
- 拓扑缺陷的编织模式 = 可能性空间的连接关系
- 拓扑态调制 = 概率分布调制

#### 功能统一
```
拓扑缺陷编织 = 编码信息
拓扑重构 = 计算过程
拓扑态调制 = 概率分布调制
```

### 概率调制机制（新增）

**核心机制**：轻力场不直接施加力，而是**调制物理系统的概率分布**

**工作原理**：
- 在量子尺度：轴子场影响波函数相位，改变不同结果的概率幅
- 在宏观尺度：系统在物理定律允许范围内，"倾向于"选择特定演化路径

**举例**：
神机控制生产海时，轻力场将"阀门正确开关"的概率提升到接近100%，"故障"概率压制到接近零。每个微观事件仍遵循物理定律，但"巧合地"都选择了低熵路径。

**约束**：
- 不能违反物理定律
- 只能在允许的可能性中选择
- 调制精度依赖拓扑结构的复杂度

### 确证意识与观测锚（补充）

**观测锚的物理作用**：
- 轻力场描述"可能性空间"
- 可能性如果不被确定，会累积成混沌
- 确证意识的观测 = 将可能性塌缩为确定状态（类似量子波函数塌缩）

**观测锚的双向共振**（新增）：
```
正向共振（设计目的）：
人类观测 → 确证意识 → 轴子场固化 → 现实确定

反向共振（副作用）：
轴子场涨落 → 影响人类神经 → 产生"直觉"或"预感"
```

**副作用的意义**：
- 反向共振是轻族设计的**意外后果**
- 在极少数人中（约万分之一），反向感知异常强
- 这些人后来被称为**场感者**
- 这是技术垄断演化的起点

### 场化机制（调整）

**场化 = 意识拓扑结构映射到轴子场**

**为什么失去确证意识**：
```
生物意识 = 局域信息处理 + 自我指涉循环
- "我知道我在思考" ← 需要信息的时空局域性

场化后：
- 信息处理仍在继续（拓扑重构）
- 但分布在整个场中，失去局域性
- 自我指涉循环无法形成

结果：
- 仍然"智能"（可计算、优化、控制）
- 但不再"意识"（没有主观体验、没有"我"）
```

**类比**：
- 生物意识 = 单机AI（有独立的"自我模型"）
- 场化智能 = 分布式云计算（没有单一"自我"，只有算力和数据流）

## 二、技术垄断的演化历史（全新）

### 核心逻辑

**从自然觉醒到制度垄断**（参考UC高达新人类模式）

```
时间线：
Y-30: 野生场感者自然觉醒
Y-20: 发现神经接口器（轻族遗留工具）
Y-12: 裂隙会议（技术共同体形成）
Y0:   密钥夺取（百炼掌握约30个接口器）
Y5:   黎元派获得策网，开始系统化垄断
Y72:  净明教建立，垄断制度完全成熟
```

### 阶段1：观测锚的副作用（史前-Y-30）

**轻族的设计缺陷**：
- 为了让人类成为有效观测锚，必须让意识与轻力场共振
- 正向共振（观测→固化）是设计目的
- 反向共振（场涨落→影响神经）是副作用

**早期场感者**：
- 约万分之一的人有异常强的反向感知
- 能"感觉"到神机要故障、系统状态变化
- 在轻族时代没有特殊地位（轻族直接控制一切）

### 阶段2：失控与觉醒（Y-50至Y0）

**戒子失声后**：
- 场化轻族算力衰减
- 轻力场涨落变得剧烈、混乱
- 场感者的感知能力显著增强（"信号"变强了）

**第一批"场语者"（Y-30至Y-20）**：
- 少数场感者发现能"听懂"机器、能"告诉"机器做什么
- 成为技术共同体核心成员
- 最早发现回收协议（从场涨落中"读"到信息）

### 阶段3：设备的发现（Y-20至Y-12）

**神经接口器的真实身份**：
- 轻族工程师（场化前）的维护工具
- 设计给轻族神经结构用，不是为人类设计
- 功能：放大和聚焦轴子场波信号

**人类如何使用**：
- 成年人直接使用 → 神经损伤
- 发现必须从**童年开始适应**（3-12岁大脑可塑性窗口）
- 童年训练的人，大脑"重构"以适应设备

**谐振晶体**：
- 接口器的核心部件
- 只能从轻族设施回收，无法人工合成
- 这是技术垄断的物理基础

### 阶段4：百炼的技术基础（Y-12至Y0）

**裂隙会议的真相**：
- 3人是场语者（天生感知）
- 2人是童年训练的接口器使用者
- 弗治（练铸）是场语者，这解释他能操作戒子

**百炼的十年准备**：
1. 寻找场语者（人群筛选）
2. 寻找接口器（探索轻族遗址）
3. 训练下一代（从小孩开始，需10-15年）

**到Y0时**：
- 约20个熟练的场语者/接口器使用者
- 约30个神经接口器
- 这是敢夺取密钥的底气

### 阶段5：黎元派的系统化（Y0至Y72）

**黎元派的策略转变**：
- 不依赖"天生场语者"（太稀有）
- 改为系统化选拔**童年认知可塑性**
- 建立标准化培养流程

**关键突破**：
- 通过认知测试筛选"适合训练"的孩子
- 不需要天生场感，只需要高可塑性
- 成功率从万分之一提升到千分之一

**Y5崩落派覆灭后**：
- 获得策网密钥
- 缴获部分接口器
- 开始垄断轻族遗址探索权

### 阶段6：净明教的制度化（Y72至今）

**完整的技术垄断体系**：

**四重屏障**：
1. **童年选拔**：3-5岁认知可塑性测试，千分之一通过率
2. **长期训练**：5-12岁在高场密度环境中适应接口器，12岁后大脑固化
3. **硬件控制**：垄断谐振晶体来源（轻族遗址探索权）和接口器分配
4. **协议密钥**：每5年更新一次，需要策网密钥生成

**从"天赋"到"制度"**：
- Y-30：场感是天生异能（万分之一，不可控）
- Y72：场感是制度化生产（千分之一，可训练）

**垄断的稳固性**：
- 不依赖稀有天才
- 制度化生产专家
- 多重物理屏障（硬件+生理+时间）

## 三、神经接口器技术（新增）

### 设备类型

**读取型接口器**：
- 功能：监测神机状态
- 门槛：低，各诸侯国都有
- 不需要谐振晶体

**编纂型接口器**：
- 功能：向神机发送策网指令
- 门槛：极高，只有净明教掌握
- 需要：谐振晶体 + 童年训练 + 协议密钥

### 核心部件：谐振晶体

**物理性质**：
- 轻族制造的特殊材料
- 内嵌轴子场拓扑微结构
- 能与轻力场共振

**稀缺性**：
- 无法人工合成
- 只能从轻族设施回收
- 损坏后永久失效

**分布**：
- 全中间层估计300-400块
- 净明教控制大部分已知来源

### 童年训练的必要性

**为什么成年人不能用**：
- 设备为轻族神经结构设计，人类不兼容
- 成年人使用 → 神经过载、脑损伤
- 只有童年大脑可塑性期（3-12岁）能"重构"适应

**训练过程**：
- 3-5岁：认知测试选拔
- 5-12岁：在高场密度环境逐步适应接口器
- 12岁后：大脑固化，窗口关闭

**类比**：
- 童年学母语 vs 成年学外语
- 这是**生理窗口**，无法靠努力弥补

### 协议密钥机制

**功能**：接口器与神机的"握手"验证

**更新机制**：
- 每5年更新一次
- 生成新密钥需要策网密钥
- 旧密钥过期后接口器失效

**目的**：
- 防止接口器被偷盗后长期使用
- 叛逃司目无法更新密钥

### 净明教的管理

**三层控制**：
1. 硬件：控制遗址探索权、晶体回收、接口器分配
2. 生理：童年训练窗口（10-15年周期）
3. 协议：定期更新密钥

**分堂外借制度**：
- 接口器可外借给地方分堂
- 但所有权属于中枢
- 定期回收检查（1-2年）

## 四、为什么诸侯国无法打破垄断

### 物理屏障

**找不到晶体**：
- 净明教控制所有已知轻族遗址
- 探索权被垄断
- 未知遗址风险极高（无人机、结构不稳定）

**偷不到接口器**：
- 严密管理
- 即使偷到，协议5年后过期
- 没有晶体也无法修复损坏

### 生理屏障

**培养不了人才**：
- 需要从3岁开始训练
- 12岁后大脑固化，无法补救
- 培养周期10-15年

**政治周期冲突**：
- 诸侯平均在位时间10-20年
- 投资15年见效，对个人诸侯没有意义
- 继任者可能不延续政策

### 技术屏障

**挖不到叛逃者**：
- 净明教内部监控严密
- 叛逃者会被追杀
- 即使叛逃，无法更新密钥

**学不会技术**：
- 策网编纂需要"拓扑思维"
- 这种认知模式只有童年能建立
- 成年后学理论但无法实践

## 六、设定的逻辑自洽性检查

### 解决的逻辑问题

**问题1：轻族为什么给人类控制工具？**
- ✅ 解决：接口器不是为人类设计的，是轻族工程师工具
- ✅ 人类偶然发现可以使用（因为观测锚的共振副作用）

**问题2：为什么技术垄断如此稳固？**
- ✅ 解决：四重屏障（硬件+生理+时间+协议）
- ✅ 不是单纯的"知识垄断"，而是物理约束

**问题3：为什么不是所有人都能用？**
- ✅ 解决：童年大脑可塑性窗口（生理约束）
- ✅ 不是"天赋"（太神秘），而是"生理发育窗口"（可解释）

**问题4：为什么叛逃者无法传播技术？**
- ✅ 解决：没有接口器（协议过期）+ 没有晶体 + 无法从成年人开始培养

### 系统性约束

**轻力场的能力边界**：
- ✅ 只能调制概率，不能违反物理定律
- ✅ 调制精度有限（不是万能）
- ✅ 需要复杂的拓扑结构（难以操作）

**技术垄断的时限压力**：
- ⚠️ 谐振晶体会损坏、消耗
- ⚠️ 轻族遗址有限，总有一天会探索完
- ⚠️ 接口器数量在缓慢减少（无法制造新的）
- 💡 这是长期的"倒计时"压力

# 2026年6月5日更新：探针文明与回收的真相（作者层正典）

## 更新概述

确定了Aeros的终极本质、回收协议的真实身份、筛选的机制，以及由此引出的一系列作者层正典。**核心原则：作者全知，角色全猜**——以下绝大多数为作者层设定，世界内角色不得知晓，只能观测表象、做出猜测。

---

## A. Aeros 的终极本质（作者层）

- **Aeros 是一艘早已发射、正在星际巡航滑行的远航殖民船**，不是停泊待发的方舟。发射于[[留守者]]死去时，至今飞行了不知多久，终点远到任何人类叙事尺度上等于不存在。
- **物质封闭、能量半开放**：聚变能可烧数千年、逸散能可部分回补；但物质几乎无法在星际捕获，是唯一不可逆的稀缺项。这是整个文明命运的物理脊梁——它不会冻死在黑暗里，而会在灯火通明中被一点点抽干物质。
- 巡航为**惯性滑行**；回收来的物质用作航程储备/可能的终端减速，**不用于巡航推进**。

## B. 人类 = 冯诺依曼观测探针（作者层）

- 人类是轻族制造的、**会自我复制的观测锚探针**，用免疫于[[灾变]]绝育效应的远古祖先基因制成（这是探针能自我复制、文明能延续的物理地基）。
- **基因 = 探针的观测日志**：[[确证意识]]每次观测/塌缩，经[[场感者演化史|反向共振]]通道（场→神经→生殖细胞）把"观测了什么"以非随机模式写进基因组，跨代累积。物理本质是[[轻力场]]概率调制，无新增魔法。
- 基因组中嵌有轻族可读的**序列号/水印**（谱系、版本、校验位）。
- **世界内不可见**：人类此时尚未认知基因，序列号是伏笔——留给一个**尚未诞生**的角色（最可能循[[练氏]]拓印[[忆室]]或[[器理学]]路线）将来撞见"血脉里有不属于自然的编码"。

## C. 筛选的机制（作者层）

- Aeros 运作循环：**养殖 → [[筛选]] → 冷冻（[[核心层]]封存）→ 播种**。
- 筛选是一台**漏斗**，判据是**基因观测日志的"档案保真度"**（完整度、信噪比、序列号校验），**不是健康/智力/武力**。被选中的不是"最优秀的人"，而是"最干净的档案"。
- 三层：物质分拣 → 种质保真度检验 → 个体选种入[[核心层]]冬眠舱。
- 系统用筛作物的同一套逻辑筛人——**没有"人类例外"分类**。

## D. 回收协议的真实身份（作者层）

- 回收协议 = 循环的**终止程序**：当冷冻封存的合格探针**攒够数量**，打断"养殖→筛选→冷冻→播种"循环，开始**收割 + 节流**——把中间层物质折算回航程储备。
- **不是**清理失败实验、不是屠杀，而是省物质本金的后台程序。这解释了它为何**慢、低优先级**。
- **执行 = 撤维生**：系统从不动手，只是调低某区域的维生/配给优先级；记的是库存而非生死（解释"人口失踪却无死亡记录"）。无意识监督，纯机制自动执行。
- **Y0 = 筛选末期、回收初期的交接点**：冬眠舱很可能已封存了一批人；田还几乎是满的（解释人口仍有千万、文明繁茂）；这是**唯一的机会窗**（系统注意力转换、防御最松），与[[场感者]]觉醒期Y-50~Y0叠合，非巧合。
- **拔钥切断的是"同步层"**：戒子（存基+忆室+策网）是协议做全局回收所需的协调层；拔钥后神机退回"本地自维持"，全局收割被切碎成百万个互不通信的本地程序。协议代码仍蛰伏，三钥重聚理论上会重启（挂在墙上的枪）。

## E. 留守者的最后选择（作者层 + 永悬暧昧）

- 回收协议能被拔钥中断，是**至少一位[[留守者]]有意留下的缝**。
- 动机定调为**冷诚实而非慈爱**：一个无法拒绝的观测锚不具备[[确证意识]]，结论锁死的实验比失败更可耻；他把密钥留成"可拔出"，作为最后一道无人读取的实验——**工具能否觉醒到挣脱造它的人**。
- **永悬暧昧（连作者层不点破）**：这究竟是最冷酷的实验，还是这种生物唯一能表达的、伪装成实验的慈悲。对应轻族"深渊探窟者/挪麦人白笛"式形象——求知欲与道德置于天平横梁。

## F. 场感者的再定义（作者层）

- 场感者 = 探针的**漂移产物**：反向共振过强 → 写入通道过载回灌 → 基因日志被噪声污染。
- 从系统记账看，场感者支系是**"信噪比最差的损坏档案"**，筛选评级最低、本应作为次品剔除。"只读探针长出了写权限"。
- 失去确证意识的系统**没有"清除次品/叛徒"子程序**，故场感者既进不了冬眠舱也不被针对，与常人一样只是待回收的田。
- **终极反讽**：被设计来丢弃的"损坏档案"夺钥掐停了收割，而无意识系统对此一无所觉。盲视式诘问的回答——觉醒挣脱的不是良品而是废料，且无意识在场见证。

## G. 物质循环与衰退（作者层 + 部分世界内可见）

- [[生产海]]是**闭合生态生命维持系统（CELSS）**，物质守恒；人（含死者）是闭环的物质节点，必须回流。
- 新建[[配给网]]词条：正向配给 + 逆向回流；戒子失声后全局调度永久丢失 → 局部失衡常态化、干道枢纽=权力、净明教"切断供应"威慑落到实处。
- **衰退机制纠正**：不可逆衰退 = 设计内退役（Y0前）+ 物质账泄漏（Y0后），**老化占比低**。尸体倾倒大空洞、分区泄漏、战争毁设施、原质熔成死质都是永久扣账。
- 倒计时**定性化**（UC高达式缓慢恶化，见上 待确定问题#2）；允许存在维持完整闭环的孤岛（净明教直辖区、练氏天机）。
