# 因果链索引

本文档整理 Levity 世界观中的核心因果关系链，帮助理解历史事件的**逻辑推演**和**必然性**。

---

## 📖 如何阅读本文档

- **箭头** `→` 表示因果关系："A导致B"
- **箭头上的文字**说明因果机制
- **方框**标注关键转折点
- **分支**表示一个原因导致多个结果

## 🔗 关键因果节点分析

### 节点1：为什么密钥夺取必然导致分裂？

```
密钥夺取 = 技术成功 + 政治问题
    ↓
问题：夺取密钥是为了阻止回收
    ├─ 但阻止之后呢？
    ├─ 人类留在中间层？还是迁往地面层？
    └─ 谁来决定？谁来执行？
         ↓
**目标一致，手段分歧 → 必然分裂**
```

### 节点2：为什么崩落派必然失败？

```
崩落派的逻辑：
├─ 强制所有人迁往地面层
├─ 用崩落制造压力
└─ 不给任何人选择的余地
    ↓
但问题：
├─ 百炼缺乏足够的武装力量
├─ 流放派联盟兵力数倍于百炼
└─ 弗治的投降导致密钥丢失
    ↓
**正确的战略 + 不足的力量 = 必然失败**
```

### 节点3：为什么净明教能崛起？

```
Y5-Y72: 黎元派的优势
├─ 持有策网（虽然秘密）
├─ 技术官僚网络遍布各地
├─ 流放派其他势力需要依赖他们维护神机
└─ 敬祖思想提供意识形态凝聚力
    ↓
同时：
├─ 百炼覆灭，激进路线被否定
├─ 流放派联盟在乱世中瓦解
└─ 没有其他势力能掌握策网
    ↓
**技术垄断 + 宗教凝聚力 = 权力基础**
```

### 节点4：为什么晓朝必须与净明教妥协？

```
Y110: [[晓武帝]]统一中间层
    ↓
但问题：
├─ 晓朝不掌握策网
├─ 净明教控制各地神机和生产海
└─ 晓朝军事强大，但技术依赖净明教
    ↓
选择：
├─ 武力夺取策网？→ 净明教威胁关闭生产海
├─ 培养自己的技术人才？→ 净明教垄断教育
└─ 与净明教结盟？→ 用政治地位换技术支持
    ↓
**军事强者 + 技术弱者 = 必须妥协**
    ↓
Y195: [[永安之约]]法定化这种妥协
```

## 🎯 使用建议

1. **理解必然性**：每个结果都不是偶然，而是前因的逻辑推演
2. **检查一致性**：添加新事件时，检查是否符合既有因果链
3. **发现空白**：如果因果链中有跳跃，可能需要补充中间事件
4. **多视角验证**：同一事件从不同视角看，因果关系可能不同
