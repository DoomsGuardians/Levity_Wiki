# 乱世势力

本词条记述[[百家之乱]]后期（约Y60~Y110）形成的主要势力。这些势力从数十年混战的废墟中浮现，最终在统一战争中被[[晓朝|晓国]]逐一征服或收编。

---

## 东庭

**中间层最大的军阀联盟。约Y40~Y110。**

东庭位于中间层顺流偏暗向区域（传统上称"东部"），是文况旧部经过数代反复兼并后形成的松散联盟。

### 形成

文况在Y26年被弑后，他的地盘分裂为四块。此后数十年，这些碎片以及周边中小军阀反复兼并、分裂、再兼并。到Y60年左右，一个名义上统一的联盟逐渐成型，被称为"东庭"——因其控制区域在干道网络中的位置而得名。

东庭包含了各种来源的军阀：文况旧部的后裔、赫连焰晚年归附后的势力残余、被吞并的小军阀、甚至虞让势力在他去世后被蚕食后的碎片。

### 特征

东庭的核心特征是**大而不强**。名义上有一个"盟主"，实际上各个军阀各怀鬼胎，把更多精力花在相互提防上，而不是扩张领土。盟主更替频繁，每一次更替都伴随着血腥的清洗。

东庭继承了文况的暴力传统，但没有继承他的效率。就像一座用碎石堆成的高塔——看起来巍峨，随时可能坍塌。

### 覆灭

[[晓武帝|姬晟]]在东庭做了十五年质子（Y62~Y77），亲眼看到了这个庞然大物的腐朽。*"东庭教会了我一件事：大不等于强。"*

Y102~Y110年的东庭之战中，姬晟利用质子时代积累的人脉和情报，以分化瓦解的方式征服东庭。晓军刚进入东庭边境，就有三个军阀投降。消息传开后，东庭内部陷入连锁崩溃。

## 南明

**乱世中最富庶的势力。约Y30~Y94。**

南明位于中间层暗向偏顺流区域（"南部"），由毕宣建立，以商业和贸易为立国之本。

### 形成

毕宣在崩落战役后南下独立，以"以商养军"的方式经营。他吸引商人和技术人员来投，保护贸易路线，建立了乱世中唯一一个以经济而非暴力为基础的稳定区域。

毕宣约在Y40年代去世后，继承者们维持了他的路线。南明逐渐演变为一个富庶的商业势力，控制了多片完整的[[生产海]]和重要的贸易节点。

### 特征

南明的核心特征是**富而不武**。它的繁荣依赖于顺流方向各势力的分裂——只要没有人统一北方，南明就安全。它的军队以雇佣兵为主，数量不少但战斗意志薄弱。

南明也是灰线商盟最活跃的区域。后来的[[行国]]虽然不直接继承南明的领土，但行国的商业传统和贸易网络很大程度上可以追溯到南明时代建立的商路。

### 覆灭

Y91年，[[净明教]]暗中关闭了南明境内三片主要生产海的神机——不是物理破坏，只是让神机"不再响应任何指令"。三个月后，面临断粮的南明投降。

南明的覆灭是统一战争中最具震撼力的事件。它证明了一件事：**在技术垄断面前，财富毫无意义。** 这也预示了[[晓朝]]未来的权力格局——谁控制了技术，谁就控制了一切。

## 玄朔

**边境军事强国。约Y50~Y101。**

玄朔位于远离中心区域的边境地带，是乱世中最独特的势力——因为它**不是从流放派演变来的**。

### 形成

玄朔的前身是一群逃到边境地区的难民和退伍军人。乱世初期，大量平民为了躲避军阀混战而向边缘地带迁移。在那里，他们面临的敌人不是其他人类，而是从失控区不断侵入的自动拆解无人机。

与无人机的长期作战塑造了玄朔的文化——彪悍、自给自足、对外界充满警惕。他们的[[生产海]]稀少，对[[黎元派]]的依赖程度远低于其他势力。这既是弱点也是优势——不富裕，但也不容易被掐住脖子。

### 特征

玄朔的核心特征是**穷而悍**。他们的军队以步兵为主，装备简陋但战斗经验丰富——常年与无人机作战的老兵，放到人对人的战场上可以以一当十。

玄朔没有复杂的政治制度，基本是部族联盟式的管理。世袭的军事首领之间通过联姻和战功来维系联盟。

### 覆灭

Y95~Y101年的玄朔之战是统一战争中最艰难的一仗。净明教关闭神机的手段对玄朔不太管用——他们本来就没有多少神机可以关闭。六年苦战，最终依靠晓国军功授爵制度激发的战斗力获胜。

姬晟战后采取安抚政策：投降将领可保留爵位，普通士兵可选择加入晓军或返乡。*"我不是来杀人的，是来统一天下的。死人不能纳税，也不能当兵。"*

玄朔的军事传统后来被[[晓朝]]有意识地保留和利用——合纵远征中，玄朔旧部是最勇猛的先锋。后来的[[燧国]]在某种程度上是玄朔传统的延续：边境、尚武、自给自足。

## 栾国

**楷国前身。约Y40~Y102。**

栾国位于中间层中部，在乱世中是一个中等势力。它的重要性不在于军事实力，而在于它意外创造的制度。

### 栾崇的实验

栾国国君**栾崇**面临一个经典的继承困境：几个有能力的儿子。按照惯例，这意味着一场血腥的继承之争。

栾崇做了一个大胆的决定：不指定继承人，让儿子们各自发展势力，最终由"实力"决定。他给每个儿子分配了领地和资源，让他们公开竞争。

这个决定的初衷是避免暗中弑杀。但它意外地产生了另一个效果——**竞争催生了人才**。为了在竞争中胜出，每个儿子都拼命招揽人才、改善治理。栾国境内出现了一种前所未有的景象：人才可以在几个"小朝廷"之间自由流动。

### 归顺与改封

Y102年，栾崇之子**栾济**在竞争中胜出后，面对晓国的统一大势，选择了主动归顺。他亲自前往晓军大营献上地图和户籍册。

栾济后来参加[[合纵远征]]，战死于Y119年，无嗣。姬恪将栾国改封给姬姓宗室，改名[[楷国]]。但栾济时代形成的"多卿并立"格局被保留了下来，成为楷国六卿制的历史基础。

## 灰线商盟

**乱世最大的黑市网络。贯穿整个百家之乱。**

灰线商盟不是军阀，不控制领土，没有军队。它是一个遍布中间层的走私和黑市贸易网络——一个在混乱中自发生长的经济寄生系统。

### 特征

战争越混乱，走私和黑市越繁荣。灰线商盟的人走遍每个角落，贩卖物资、情报、通行权，甚至贩卖人口。他们没有统一的组织结构，而是由松散的商人家族和贸易网络组成。

灰线商盟的核心价值观只有一条：**利润至上。** 他们不在乎谁统治谁，只在乎贸易路线是否畅通。这种绝对的商业主义让他们成为乱世中最中立也最不可信任的力量。

### 与郑桓的关系

郑桓的情报网络和灰线商盟有密切的合作关系。郑桓死后，他的部分情报网络被商盟吸收。

### 后续

[[晓朝]]建立后，灰线商盟选择"洗白"——向晓朝表示臣服，利用积累的财富和人脉控制了几个贸易节点城市。Y180年，晓朝正式册封商盟首领为诸侯，建立[[行国]]。

## 谱系总图

```
Y0 密钥夺取
 │
 └─ 流放派联军
     │
     ├─ 孟遂（Y12死）→ 联盟瓦解
     ├─ 文况（Y26被弑）→ 旧部反复兼并 → 东庭（Y102~110亡）
     ├─ 毕宣（Y40s亡）→ 南明（Y91~94亡）
     ├─ 虞让（Y70s亡）→ 势力被东庭蚕食
     ├─ 郑桓（Y73亡）→ 情报网→灰线商盟→行国
     ├─ 栾崇 → 栾济归顺 → 改封楷国
     └─ 晓国（边缘小势力）→ 姬晟变法 → 统一天下

独立起源：
     ├─ 赫连焰（囚犯暴动）→ 边境政权 → 归附东庭
     ├─ 玄朔（边境难民）→ 军事强国（Y95~101亡）
     └─ 灰线商盟（黑市网络）→ 行国
```
