# Aeros

**Aeros**是[[轻力场文明|LFC]]建造的远程栖居体，一个三层同轴圆柱结构的宇宙殖民船，也是人类生存的世界。

---

## 历史

### Aeros-0

Aeros的前身是**Aeros-0**，是LFC为大宇宙远航设计的殖民船，内部包含自动化系统和生产设施。

### 改造为Aeros

[[灾变]]和[[场化]]后，LFC需要运输和培养[[观测锚]]。由于观测锚的生存资源需求远高于场化后的LFC，且剩余未场化的个体没有足够时间完全改建，Aeros-0只经历了模块改装和流程重写，成为现在的Aeros。

---

## 结构

Aeros采用三层同轴圆柱体结构，由内向外分别为：

### [[核心层]]
- 半径：约10公里
- 功能：发光面（模拟日夜光照与季节温差）、冬眠载荷存放、骨干系统

### [[中间层]]
- 内壁半径：约710公里
- 厚度：约2公里
- 功能：栖居/养殖区域，[[观测锚]]的主要生存空间，[[生产海]]所在地

### [[地面层]]
- 内壁半径：约772公里
- 厚度：约5公里（主装甲带）
- 功能：最外层结构，机械支撑与保护壳

### 层间结构
- **天空间距**：核心层与中间层之间约700公里，容纳完整大气层、电离层及低轨等效区域
- **装甲间隙**：中间层与地面层之间约60公里，多层复合装甲结构

### 总体参数

| 参数 | 数值 |
|------|------|
| 总半径 | 约777公里 |
| 总直径 | 约1554公里 |
| 圆柱长度 | 约2500公里 |
| 自转周期 | 约28分钟 |
| 中间层总面积 | 约1115万平方公里（约等于欧洲面积） |

作为参照：谷神星直径约950公里，月球直径约3474公里。Aeros的体量介于两者之间。

### 层间连接
各层之间存在支柱，承担：
- 物质输送
- 能量输送与回收
- 气压调节与环境控制

## 物理环境

Aeros通过自转产生离心力模拟重力，[[轻力场]]在此基础上进行全面修正：

- 轻力场抹平了旋转圆柱体的物理异常（如科里奥利偏转、高空重力锐减等），使物理规律在居民感知范围内表现"正常"
- 人类不知道自己生活在圆柱体中，不是因为物理线索被大气遮蔽，而是因为轻力场让物理规律本身看起来就是正常的
- 700公里厚的大气柱提供充分的大气散射，天空呈现为弥漫的穹顶光幕，无法看到对面的地表
- 核心层的光照经大气散射后成为整体天光，有明暗区域但无清晰"太阳"
- 核心层按24小时周期控制明暗，全区域同步日夜
- 按365天周期模拟季节温差
- 推测Aeros的目的地与地球环境相近

## 运作流程

Aeros的[[观测锚]]管理遵循四阶段流程：

1. **养殖**：维持观测锚群体，引导差异化发展
2. **筛选**：评估观测产出质量
3. **冷冻**：将有价值个体送入冬眠舱
4. **播种**：迁移到新场域

由于[[中间层]]资源无法支撑全程航行，在筛选末期会使用[[轻力场]]对中间层进行场级解构与回收。
