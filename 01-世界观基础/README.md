# 01-世界观基础

本目录包含 Levity 世界观的深层设定，涵盖远古轻力场文明(LFC)、Aeros物理结构、核心控制系统、人类地理四个方面。

---

## LFC与起源

关于轻力场文明的起源、灾变与场化，以及人类作为观测锚的本质。

- [[轻力场文明]] - Aeros的建造者，远古高等文明
- [[轻力场]] - 世界的基础物理介质，LFC的核心发现
- [[灾变]] - LFC失去繁殖能力的转折点
- [[场化]] - LFC投影到统一轻力场，成为无意识智能
- [[确证意识]] - 意识与观测的关键概念
- [[观测锚]] - 人类在这个世界中的本质定位

**推荐阅读顺序**: 轻力场文明 → 灾变 → 场化 → 确证意识 → 观测锚

---

## 物理结构

Aeros作为三层同轴圆柱体的物理构造与各层特征。

- [[Aeros]] - 远程栖居体，三层同轴圆柱体，总半径约777公里
- [[核心层]] - 最内层，提供均匀光照的穹顶结构
- [[中间层]] - 人类主要栖居区，2公里厚结构板+700公里大气层
- [[地面层]] - 最外层，流放地与未知领域
- [[生产海]] - 中间层的生命维持器官，生物培养与资源生产
- [[元枢]] - 神机网络总站，已毁（Y5崩落战役）
- [[大空洞]] - 崩落战役造成的巨大结构缺失，重力异常区
- [[破碎群岛]] - 脱离戒子控制的空中城邦
- [[隔离笼]] - 特殊结构设施

**推荐阅读顺序**: Aeros → 核心层/中间层/地面层 → 生产海 → 元枢 → 其他特殊结构

## 人类地理

人类社会命名的区域与要塞，承载着百家之乱的历史记忆。

**主要区域**
- [[梁津]] - 百炼与流放派交界地带，断梁之溃发生地
- [[荒津]] - 中间层南部区域，荒津之战战场
- [[央泽]] - 中部大型生产海，分海之议共管区
- [[天机]] - 练氏领地，密钥存放地，极致的壁中城

**要塞关隘**
- [[断梁关]] - 梁津主要关口，断梁之溃发生地

**推荐阅读顺序**: 先了解[[中间层]]和[[方位体系]]，再阅读具体区域

---

## 核心系统

控制Aeros运行的核心技术系统。

- [[戒子系统]] - Aeros的核心控制系统，人类不完全理解的智能
- [[神机网络]] - 分布式控制网络，遍布中间层的管道和节点
- [[密钥]] - 戒子系统的三枚权限锚，不可分割或复制
- [[策网]] - 全网指令输出密钥，控制所有神机的指令权
- [[忆室]] - 记忆与策略密钥，存储LFC知识
- [[存基]] - 全局感知密钥，监控整个Aeros的传感器网络

**推荐阅读顺序**: 戒子系统 → 神机网络 → 密钥 → 三枚密钥详述
